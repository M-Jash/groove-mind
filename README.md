# 🎵 GrooveMind – AI Music Genre Prediction

GrooveMind is a web-based Music Genre Prediction application that uses Machine Learning to classify audio tracks into different music genres. The application provides an intuitive interface where users can upload an audio file and receive the predicted genre instantly.

## 🚀 Features

- 🎼 Upload audio files for prediction
- 🤖 AI-powered music genre classification
- ⚡ Fast and accurate predictions
- 🎨 Modern and responsive UI
- 📱 Mobile-friendly design
- 🌙 Clean user experience

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

### Machine Learning
- Music Genre Classification Model
- Dataset-based prediction system

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/M-Jash/groove-mind.git
```

Move into the project directory

```bash
cd groove-mind
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

## 🎯 How It Works

1. Open the application.
2. Upload a music/audio file.
3. The AI processes the input.
4. The model predicts the music genre.
5. The predicted genre is displayed on the screen.

## 📊 Dataset

The prediction model is trained using a music genre dataset containing multiple genres and extracted audio features.
